# AttendEase – GPS-Based Attendance Management System

A web-based attendance management system using GPS location.

## Technologies Used
- React.js
- Vite
- Node.js
- Express.js
- PostgreSQL

## Features
- User Login
- GPS-Based Attendance
- Student and Employee Profile Management
- Attendance Management
- Attendance Reports Dashboard
- Attendance Summary
- Student-wise Reports
- CSV Report Download
